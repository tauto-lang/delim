# Delim

- [delim](totes/delim) — Tauto で書く UI ライブラリ。signal、描画先に依らない要素の木、store、resource と suspense、`view!`
- [delim-html](totes/delim-html) — HTML の書き出しと DOM の描画先、書いてよいものの許可リスト、HTML の `view!`
- [delim-spa](totes/delim-spa) — ブラウザーの中で動かすアプリ向けのルーター `route!`
- [delim-ssg](totes/delim-ssg) — ページを前もって HTML のファイルに書き出す静的サイト生成
